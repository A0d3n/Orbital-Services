# Orbital Services

Orbital Services est une application web auto-hébergée pour les joueurs de **Star Citizen**. Elle réunit :

- une **chronologie** de l'univers de Star Citizen ;
- le **Star Viewer**, une carte du temps pour se repérer dans cette chronologie ;
- les **Comm-Links** officiels de Roberts Space Industries, consultables et filtrables.

Le but du projet est d'offrir aux joueurs un outil simple et léger pour explorer l'univers du jeu, sur leur propre serveur.

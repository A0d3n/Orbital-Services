# Orbital Services

Orbital Services est une application web auto-hébergée pour les joueurs de **Star Citizen**. Elle réunit au même endroit :

- une **chronologie** de l'univers de Star Citizen ;
- le **Star Viewer**, une carte du temps pour se repérer dans cette chronologie ;
- un **carnet de bord** personnel pour consigner ses sessions de jeu, avec import depuis le fichier `Game.log` du jeu et export en CSV ou JSON.

Le but du projet est d'offrir aux joueurs un outil simple, léger et privé pour suivre leur parcours dans l'univers du jeu, sur leur propre serveur.
